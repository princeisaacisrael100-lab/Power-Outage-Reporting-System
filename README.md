
  # Power Outage Reporting System

  This is a code bundle for Power Outage Reporting System. The original project is available at https://www.figma.com/design/Re57Fyr37pgVowzp5J73zB/Power-Outage-Reporting-System.

  ## Running the code

  Install dependencies with `pnpm install` or `npm install`.

  Start the development server with `pnpm dev` or `npm run dev`.

  ## Mock data

  The app includes a generated dataset of 120 outage reports for UI testing, including investigating, repairing, and resolved incidents.
